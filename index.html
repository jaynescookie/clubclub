저장 설정 확인 중

GitHub 토큰을 등록하면 입력할 때마다 data.json이 자동 저장됩니다. 등록하지 않으면 입력 내용이 이 브라우저에만 남고, 발행 버튼으로 파일을 내려받아 직접 올려야 합니다.

  1. GitHub 로그인 → 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token 클릭
  4. Token name 아무거나(golf-app), Expiration은 No expiration 또는 1년
  5. Repository access → Only select repositories → 이 저장소 선택
  6. Permissions → Repository permissions → Contents 를 Read and write 로
  7. Generate token → 나온 문자열 복사 (한 번만 보입니다. 메모해 두세요)
  8. 위 칸에 붙여넣고 토큰 등록

자동 저장이 켜져 있습니다. 입력하면 바로 저장소에 반영되고, 회원 화면에는 약 1분 뒤 나타납니다.

운영 규칙

핸디캡 — 총타수 − 72. 98타 = +16, 70타 = −2. 값이 작을수록 잘 친 것입니다.
표기 — 핸디는 모두 정수로 표시합니다. 평균을 낼 때 소수점은 반올림합니다(0.5 미만 버림, 0.5 이상 올림). 예: 평균 21.4 → 21, 21.5 → 22.
기본 적립 — 라운드 참가 1회당 10A.
보너스 — 그 회원의 직전 평균 핸디보다 좋은 핸디를 기록하면 +5A (총 15A). 기준은 그 회원이 마지막으로 라운드한 달의 평균 핸디이므로, 한 달을 쉬어도 기준이 유지됩니다. 라운드 기록이 아직 없으면 관리자가 등록한 기존 핸디캡을 쓰고, 그것도 없으면 기준이 없어 기본 10A만 적립됩니다.
기준 갱신 — 매월 1일 자동 반영. 9월 라운드는 8월 평균과 비교하고, 9월을 쉬었다면 10월에도 8월 평균이 기준입니다. 라운드 기록 표의 "기준" 열에 어느 달 값이 쓰였는지 표시됩니다.
내기 — 회원 간 코인 이동. 진 사람에서 이긴 사람으로 옮겨가며 전체 총량은 변하지 않고, 잔액은 마이너스가 될 수 있습니다.
특별대출 — 코인이 부족해 내기에 못 끼는 회원을 위한 제도입니다. 1회 50A, 연 2회까지 관리자가 실행합니다. 갚을 때는 이자 10%를 더해 55A를 한 번에 갚습니다. 나눠 갚지 않습니다.
상환 방법 — 코인이 55A 이상 모이면 관리자가 장부 탭에서 상환 버튼을 눌러 처리합니다. 55A가 안 되면 버튼이 눌리지 않으니 잔액이 마이너스가 될 일은 없습니다. 얼마가 더 필요한지는 내 이름을 눌러 확인할 수 있습니다.
수동 가감 — 관리자가 코인을 직접 더하거나 뺄 수 있습니다. 이전 장부 이관, 이벤트 상금, 정정 등에 사용하며 이력이 남습니다.
권한 — 조회는 누구나, 입력·수정은 관리자만.
